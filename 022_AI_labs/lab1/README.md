
This folder contains a small comparison of rule-based decisions and a probability-threshold decision, plus an extended rule checker.

## Files
- `lab1_compare.py`: compares the symbolic rule and probability threshold using the four cases from the manual.
- `lab1_rules.py`: adds two named conditions: `identity_verified` and `eligibility_confirmed`. It runs exactly four core test cases.
- `Lab1_Report.docx`: report with the timeline, code design, test results, limitations, and reflection.
- `outputs/`: captured console output from the scripts.

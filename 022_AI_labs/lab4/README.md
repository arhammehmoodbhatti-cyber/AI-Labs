This folder contains the A* heuristic audit and comparison with Uniform Cost Search for Lab 4.

## Files
- `lab4_astar_audit.py`: calculates g, h and f, records the processing trace, checks consistency and tests an overestimate.
- `Lab4_Report.docx`: manual values, route comparison, results and reflection.
- `outputs/`: saved terminal results.

## Run
```bash
python lab4_astar_audit.py
```

This folder contains the graph search tasks for Lab 3.

## Files
- `lab3_search.py`: BFS and DFS paths and processing order on the supplied A-G graph.
- `lab3_depth_search.py`: DLS and IDDFS with FOUND, CUTOFF and FAILURE results.
- `lab3_ucs.py`: weighted graph search using a priority queue and an independent path-cost check.
- `Lab3_Report.docx`: trace, results, comparison and reflection.
- `outputs/`: saved terminal results.

## Run
Run these commands from this folder:

```bash
python lab3_search.py
python lab3_depth_search.py
python lab3_ucs.py
```

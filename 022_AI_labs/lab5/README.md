This folder contains Minimax and Alpha-Beta Pruning tasks for Lab 5.

## Files
- `lab5_minimax.py`: Minimax with a leaf-evaluation counter and a hand-trace-ready tree.
- `lab5_alphabeta.py`: Alpha-Beta search with alpha and beta bounds and a leaf counter.
- `lab5_ordering.py`: compares the effect of changing leaf order.
- `Lab5_Report.docx`: trace, results, comparison and reflection.
- `outputs/`: saved terminal results.

## Run
```bash
python lab5_minimax.py
python lab5_alphabeta.py
python lab5_ordering.py
```

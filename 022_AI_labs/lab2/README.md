This folder contains the smart classroom example and PEAS specifications for a delivery robot and an LLM-based student-support agent.

## Files
- `lab2_percepts.py`: original reflex-style classroom policy and required percept sequence.
- `lab2_model.py`: remembers the previous target mode and reports whether a new command should be sent.
- `lab2_check.py`: tests repeated percepts, both exact temperature boundaries, a mode change, and the empty-room case.
- `Lab2_Report.docx`: PEAS tables, environment classifications, assumptions, trace, limitations, and reflection.
- `outputs/`: captured output from the three scripts.
